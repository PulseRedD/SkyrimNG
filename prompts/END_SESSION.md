# SkyrimNG — End Session Prompt

Copy at the end of a work session:

> Close out this SkyrimNG session. Review the work actually performed, verify GitHub changes and any available test results, then update the relevant `PROJECT_STATE.md` files and `sessions/LATEST_HANDOFF.md` in SkyrimNG. Include: date, session objective, decisions and rationale, completed work with file paths and commit references, tests performed and outcomes, unresolved issues, blockers, changed assumptions, and the next 3–5 actionable steps. If appropriate, archive the previous handoff under `sessions/archive/`. Clearly separate verified completion from proposed work. Do not claim local MO2 actions or tests occurred unless supported by evidence. Report any GitHub write failures.


**Mandatory safety rule:** All state and handoff updates must be committed to a non-main branch and proposed through a PR. Do not write directly to `main` or merge without explicit owner approval. If the PR is pending, identify it as proposed work rather than accepted project state.
